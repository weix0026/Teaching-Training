# LP Graphic Solution Studio

Interactive static website for teaching the two-variable graphic solution process from the Week 2 Introduction to LP lecture deck.

Open `index.html` in a browser. The page runs without a server or external dependencies.

Built-in examples:

- Warm-up feasible-region problem: `max Z = 2x1 + x2`
- Poet and woods problem: `max Profit = 90x1 + 120x2`
- River pollution problem: `min Pollution = x1 + 1.5x2`

The model editor accepts a custom two-variable LP with up to five displayed constraints. Nonnegativity is always included by the graph engine.
