# Dynamic Forest Model Studio

A dependency-free interactive companion to F422 Lab 6. Open `index.html` directly in a modern browser.

The lesson and simulator use the supplied Lab 6 data:

- Initial state: A11 = 100 ha, A21 = 200 ha, A31 = 50 ha, A41 = 150 ha
- Three 10-year transition periods
- Age-class yields: 50, 250, 500, and 600 m³/ha
- Harvest variables Xij and state variables Aij
- Clearcut area is reforested into Age Class 1
- Forest older than 30 years is pooled into Age Class 4
- Final steady-state constraints Ai3 = Ai4

Reference Q1 and Q3 outputs are transcribed from `Lab6DM.xlsx`. The live sliders are a state-transition simulator, not an optimizer.
